# Mempool

This repository contains a Rust-based project named **Mempool**. Below is an overview of the project structure and instructions for setup and usage.

## Project Structure

```text
mempool/
├── .env                # Environment variables file (ignored by Git)
├── .gitignore          # Git ignore rules
├── Cargo.lock          # Cargo lock file for dependencies
├── Cargo.toml          # Cargo configuration file
├── env.sample          # Sample environment variables file
├── src/
│   └── main.rs         # Main source code file
└── target/             # Build output directory (ignored by Git)
```

## Setup

1. **Clone the Repository**:

   ```sh
   git clone <repository-url>
   cd mempool
   ```

2. **Install Rust**:
   Ensure you have Rust installed. If not, install it using [rustup](https://rustup.rs/):

   ```sh
   curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
   ```

3. **Set Up Environment Variables**:
   Copy the `env.sample` file to `.env` and update the values as needed:

   ```sh
   cp env.sample .env
   ```

   Example `.env` file:

   ```text
   MAIL=cexom36573@bocapies.com
   WEBSOCKET_URL=wss://go.getblock.io/your code
   ```

4. **Build the Project**:
   Use Cargo to build the project:

   ```sh
   cargo build
   ```

5. **Run the Project**:
   Execute the compiled binary:
   ```sh
   cargo run
   ```

## Notes

- The `target/` directory and `.env` file are ignored by Git as specified in the `.gitignore` file:

  ```ignore
  # Created by https://www.toptal.com/developers/gitignore/api/rust
  # Edit at https://www.toptal.com/developers/gitignore?templates=rust

  ### Rust ###
  # Generated by Cargo
  # will have compiled files and executables
  debug/
  target/

  # Remove Cargo.lock from gitignore if creating an executable, leave it for libraries
  # More information here https://doc.rust-lang.org/cargo/guide/cargo-toml-vs-cargo-lock.html
  Cargo.lock

  # These are backup files generated by rustfmt
  **/*.rs.bk

  # MSVC Windows builds of rustc generate these, which store debugging information
  *.pdb

  .env

  # End of https://www.toptal.com/developers/gitignore/api/rust
  ```

- The `Cargo.lock` file is included in version control because this project is an executable, not a library. For more details, see the [Cargo documentation](https://doc.rust-lang.org/cargo/guide/cargo-toml-vs-cargo-lock.html).
